
# 🎮 Gamora — Sistema de Gerenciamento de Jogadores

O **Gamora** é um sistema de gerenciamento de jogadores desenvolvido em JavaScript, executado no terminal. O projeto permite cadastrar e gerenciar uma equipe de jogadores, controlar suas pontuações e calcular a média de desempenho da equipe.

O projeto foi desenvolvido com o objetivo de praticar os fundamentos da programação em JavaScript, incluindo funções, arrays, objetos, estruturas condicionais e laços de repetição.

## 🚀 Funcionalidades

- **Cadastrar jogadores:** registra o nome, a função e a pontuação de cada jogador.
- **Excluir jogadores:** remove jogadores cadastrados pelo nome.
- **Listar equipe:** exibe os jogadores e suas respectivas informações.
- **Calcular média:** calcula a média das pontuações de todos os jogadores cadastrados.
- **Atualizar pontuações:** permite modificar a pontuação de um jogador.
- **Menu interativo:** disponibiliza opções para navegar pelas funcionalidades do sistema.

Antes de executar o projeto, você precisa ter instalado:

- [Node.js](https://nodejs.org/)

## ⚙️ Como executar o projeto

**1. Clone o repositório**

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Substitua `URL_DO_SEU_REPOSITORIO` pela URL real do repositório no GitHub.

**2. Acesse a pasta do projeto**

```bash
cd modulo-02-javascript
```

**3. Instale as dependências**

```bash
npm install
```

**4. Execute o programa**

```bash
node repeticoes.js
```

## 💻 Exemplo de utilização

Ao iniciar o programa, será apresentado um menu com as seguintes opções:

```text
------- Sistema de Gamers -------
1 - Cadastrar jogador
2 - Deletar jogador
3 - Mostrar equipe
4 - Cálculo de média da equipe
5 - Atualizar pontos do jogador
6 - Sair
```

Escolha uma opção e siga as instruções exibidas no terminal.
